Как отдельное приложение на телефон

Твой браузер готов установить «Учебный планер» в один клик:

🤖 Для Android (Google Chrome / Яндекс):
  1. Если открыто внутри чата — нажми кнопку открытия в отдельном окне браузера (или скопируй адрес).
  2. Нажми на три точки (⋮) в правом верхнем углу браузера.
  3. Выбери пункт «Добавить на гл. экран» или «Установить приложение».
  4. Подтверди — иконка «Учебный планер» появится на рабочем столе телефона!
🍎 Для iPhone (Safari):

Нажми «Поделиться» (квадрат со стрелкой вверх) внизу экрана → выбери «На экран „Домой“».
